# Red Flag Day: submission text

## Project description (≤ 150 words)

Red Flag Day is a beach rescue party game for one laptop and four phones. The rip is pulling swimmers past the buoys, and two lifeguard crews race to bring them in. Each crew has a Driver, who steers a jet ski but sees only a few metres around it, and a Navigator, who sweeps a drone for sandbars, rocks and jellyfish, marks the two worst dangers, and scans the beach radio for the swimmer. Both crews chase the same swimmer on the same map, so every rescue is a race and talking is the whole game. The laptop runs the only simulation, a pure seeded TypeScript engine synced to the phones over Supabase Realtime, and each seat sees only what its role allows. Every reef layout is path-checked so each swimmer is reachable. It ends with the rescued swimmers stepping onto the sand, one by one.

(147 words)
